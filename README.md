# ウチナーヤマトグチ 合成音声のネイティブ確認セット

作成日時: 2026-11-10T11:36:31+09:00（Asia/Tokyo）

ネイティブの協力者に、合成音声と台本が対応しているかを見てもらうためのセットです。発話は **13会話・104発話** です（約100発話。会話の途中で切らないためこの件数にしています）。

## 使い方

1. 公開URLをブラウザで開き、冒頭の手順を読む（ローカルでは `index.html` を開く）。
2. 「確認を始める／続きから再開」を押し、各音声の「読みの正しさ」「話し方の自然さ」を選ぶ。コメントは任意。2音声ある発話は両方を確認する。
3. 「回答ファイルを共有」を押し、対応端末ではLINE・メール等で依頼者へ送る。JSON共有に非対応なら、同じ内容のTXTファイルで共有を試す。
4. 直接共有できない場合はJSONファイルを保存し、依頼者へのメッセージに添付する。CSV出力も可能。
5. 回答は同じ端末・ブラウザ・URLの中に保存される。**自動送信はしない**。共有先アプリでの送信完了を確認する。

GitHub Pagesは公開サイトです。`noindex, nofollow, noarchive` を指定していますが、閲覧を制限する認証機能はありません。URLを知る第三者も閲覧できます。音声・台本は公開リポジトリからも参照できます。

表計算ソフトで見る場合は `review_sheet.csv` を使う。

## 音声の条件

- 既存の Gemini 3.8 Flash TTS（2026-11-05 生成済み）を再利用しており、今回の新規合成・課金呼び出しはしていない。
- **指定の読みで合成**: 人手で付けた話し言葉のカナを入力して作った音声。104発話すべてにある。
- **表記のまま合成**: 漢字かな交じりの台本をそのまま入力して作った音声。8会話・64発話だけにある。声とスタイルは対になる指定読み音声と同じ。

台本は創作の日常会話で、ウチナーヤマトグチ寄りの語尾や言い回しを控えめに入れてある。指定読みは同僚レビュー済みだが、**ネイティブ確認はまだない**。合成音声そのものを現地の人の発話とは扱わない。

この確認結果を学習データや評価の正解へ自動では使わないこと。

## ファイル

- `index.html`: 聞き比べ用の確認表
- `review_sheet.csv`: 同じ項目の表（判定欄は空）
- `MANIFEST.json`: 選定理由と各音声のハッシュ
- `audio/phonetic/`, `audio/orthographic/`: MP3（元は 24 kHz mono WAV。確認用に 64 kbps へ変換。原本WAVはGPU上に残してある）
